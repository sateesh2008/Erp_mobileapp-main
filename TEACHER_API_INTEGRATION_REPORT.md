# Teacher API Integration Report

## Client and authentication

| Item              | Verified implementation                                                                                                                           |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Base URL          | `EXPO_PUBLIC_API_URL`, default `https://educampus360.com/api`, in `src/services/api.js`                                                           |
| Authentication    | `POST /auth/login`, fallback `POST /login`; the returned bearer token is passed through `apiRequest`                                              |
| HTTP client       | `apiRequest` supports GET, POST, PUT, PATCH, DELETE, query parameters, JSON bodies, bearer auth, response parsing, and `ApiError` status messages |
| Teacher routing   | `src/app/index.tsx` routes the authenticated Teacher session to `TeacherPortalScreen`                                                             |
| Bottom navigation | `TeacherPortalScreen` preserves Home, Attendance, Gate Pass, Homework, Leave Management, Timetable, and More; More remains the final menu item    |

## Pending or requiring backend confirmation

- Teacher announcements/faculty notices are not connected to a Teacher screen. The dashboard currently uses `/holidays` for its notice board and the separate `/notices` method is not called.
- The repository contains no backend source or authoritative API specification, so dashboard route selection and the gate-pass singular/plural route split cannot be verified here.
- WhatsApp absent alerts are explicitly simulated by `sendAbsentWhatsAppAlert`; no alert endpoint is present in the discovered services.
- Teacher leave response fields are normalized with parent/student-oriented UI labels and should be checked against the faculty leave response contract.
- Hall-ticket service behavior is represented in the exams UI, but no dedicated hall-ticket endpoint was discovered in the current Teacher service layer.
